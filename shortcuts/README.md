# iOS 捷徑：打卡入口

三支捷徑，全部只用內建動作，不需額外 App。`<HOST>` 換成你的 Hosting 網址（如 `https://xxx.web.app`），`<TOKEN>` 換成 `WRITE_TOKEN`。

> 安全提醒：token 明文存在捷徑內。**不要用 iCloud 連結分享這些捷徑。** 外流時到 Firebase 換 Secret 並重新部署即可。

---

## 捷徑 A：「我平安」（零互動）

| # | 動作 | 設定 |
|---|---|---|
| 1 | 取得目前位置 | 精確度：最佳 |
| 2 | 取得 URL 內容 | URL：`<HOST>/api/checkin`<br>方法：POST<br>標頭：`X-Write-Token` = `<TOKEN>`<br>請求本文：JSON |
|   | └ JSON 欄位 | `lat`（數字）= 位置 › 緯度<br>`lng`（數字）= 位置 › 經度<br>`source`（文字）= `shortcut`<br>`clientAt`（文字）= 目前日期，格式 ISO 8601 |
| 3 | 從輸入取得字典值 | 取得 `nextDeadlineAt` 的值，輸入：URL 內容 |
| 4 | 格式化日期 | 日期：字典值；格式：自訂 `MM/dd HH:mm`；時區：Asia/Taipei |
| 5 | 顯示通知 | 「已打卡 ✅ 下次期限（台北）：{格式化日期}」 |

**觸發方式建議**：動作按鈕（iPhone 15 Pro 以上）、控制中心的「捷徑」控制項（iOS 18）、背面輕點，或對 Siri 說「我平安」。這些都不會開啟捷徑 App。

**失敗行為**：無網路或伺服器錯誤時，系統會顯示紅色錯誤橫幅，沒有自動重送。稍後再按一次即可。

## 捷徑 B：「我平安＋預告」

| # | 動作 | 設定 |
|---|---|---|
| 1 | 取得目前位置 | 精確度：最佳 |
| 2 | 從選單選擇 | 提示：「下次回報」；選項：預設 / 6 小時 / 12 小時 / 24 小時 / 飛行 16 小時 / 自訂 |
|   | 每個選項 | 「設定變數 `nextHours`」= 對應數字；「預設」不設定；「自訂」用「要求輸入（數字）」後設定變數 |
| 3 | 要求輸入 | 提示：「備註（可空）」；類型：文字；允許空白 → 變數 `note` |
| 4 | 取得 URL 內容 | 同捷徑 A，JSON 多兩個欄位：`nextHours`（數字，若未設定則不加此欄位）、`note`（文字） |
| 5–7 | 同捷徑 A 步驟 3–5 | |

用 Siri 執行時，步驟 3 可以直接口述備註。

## 捷徑 C：「預告離線」

| # | 動作 | 設定 |
|---|---|---|
| 1 | 取得 URL 內容 | URL：`<HOST>/api/trips/active`；方法：GET；標頭：`X-Write-Token` = `<TOKEN>` |
| 2 | 從輸入取得字典值 | 取得 `id` → 變數 `tripId` |
| 3 | 從選單選擇 | 「離線多久」：8 / 12 / 16 / 24 / 自訂 → 變數 `hours` |
| 4 | 取得 URL 內容 | URL：`<HOST>/api/trips/{tripId}/offline`；方法：POST；標頭同上；JSON：`hours`（數字） |
| 5 | 顯示通知 | 「已預告離線，期間不會警報」 |

也可以在家人群組直接對 bot 輸入 `離線 16`，效果相同。

## 自動化（只用來提醒，不要自動打卡）

- **每日固定時間**：例如 09:00 與 21:00，「顯示通知：該報平安了」。iOS 17 起可設為「立即執行」，不需確認。
- **進階**：自動化先 GET `<HOST>/api/trips/active` 取 `nextDeadlineAt`，換算後顯示「距離期限還有 X 小時」。

**不要**用自動化定時執行捷徑 A。自動送出位置會讓「沒打卡」失去意義。

## Android

用 Tasker、MacroDroid 或 HTTP Shortcuts 做同樣的 HTTP POST 即可，欄位相同。

## 捷徑 D：「用照片報平安」（分享表單）

拍完照後，在相機縮圖或 Photos 按「分享」→ 選這個捷徑。也可以從主畫面執行，會跳出照片選擇器。

**捷徑設定**：右上「i」→ 開啟「顯示於分享表單」，接收類型只勾「影像」。

| # | 動作 | 設定 |
|---|---|---|
| 1 | 如果 | 「捷徑輸入」沒有值 → 「選取照片」（不允許多選）→ 設定變數 `照片`；否則 設定變數 `照片` = 捷徑輸入 |
| 2 | 取得影像的詳細資訊 | 取得「位置」自 `照片` → 變數 `位置` |
| 3 | 如果 | `位置` 沒有值 → 「取得目前位置」→ 設定變數 `位置`（照片沒有 GPS 時退回目前定位） |
| 4 | 取得影像的詳細資訊 | 取得「拍攝日期」自 `照片` → 格式化日期：ISO 8601（含時間）→ 變數 `拍攝時間` |
| 5 | 調整影像大小 | `照片`，寬度 1600、高度自動 |
| 6 | 轉換影像 | 轉成 JPEG，品質 中，**不保留詮釋資料**（位置另外傳） |
| 7 | 要求輸入 | 「備註（可空）」→ 變數 `備註`（不想每次輸入可刪掉這步） |
| 8 | 取得 URL 內容 | URL：`<HOST>/api/checkin/photo`<br>方法：POST<br>標頭：`X-Write-Token` = `<TOKEN>`<br>請求本文：**表單**<br>`lat`（文字）= 位置 › 緯度<br>`lng`（文字）= 位置 › 經度<br>`takenAt`（文字）= 拍攝時間<br>`note`（文字）= 備註<br>`clientAt`（文字）= 目前日期（ISO 8601）<br>`photo`（檔案）= 轉換後的影像 |
| 9 | 從輸入取得字典值 | `nextDeadlineAt` |
| 10 | 顯示通知 | 「已用照片打卡 📷 下次期限（台北）：{格式化日期}」 |

- 照片會縮到 1600px（約 300 KB），上限 8 MB。
- 伺服器仍以**收到的時間**計算下次期限；拍攝時間只用來顯示，家人頁會標「拍攝於 …」。
- 沒訊號時拍的照片，之後有網路再分享即可補送。
